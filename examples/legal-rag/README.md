# 本地法务 PDF RAG 实验 | Local legal PDF RAG experiment

本目录保留原始 Python 实验脚本，探索 PDF 文本抽取、文本切分、Chroma 向量检索、Ollama 本地生成，以及 Streamlit/CLI 交互。详细的原始环境说明见 [ORIGINAL_README.md](ORIGINAL_README.md)。

This folder preserves the original Python experiment scripts exploring PDF text extraction, chunking, Chroma vector retrieval, local generation with Ollama, and Streamlit/CLI interaction. See [ORIGINAL_README.md](ORIGINAL_README.md) for the original setup notes.

这是来源项目中的原型代码，版本和依赖可能不一致，尚未在本次整理中执行或验证。仓库不包含法务 PDF 样本。仅用于技术学习，不提供法律意见；正式使用前应核查原文、法规时效、检索质量和模型输出。

These are prototype scripts from the source project; versions and dependencies may differ, and they were not run or validated as part of this curation. Legal PDF samples are not included. For technical learning only, not legal advice. Before practical use, check source documents, legal currency, retrieval quality, and model output.
